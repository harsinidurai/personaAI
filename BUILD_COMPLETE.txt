================================================================================

Authentication

Chat

GET    /api/chat/history/:sessionId Get session messages

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Dependencies won't install
Fix: rm -rf node_modules && npm install

Issue: MongoDB connection error
Fix: Run 'mongod' in separate terminal

Issue: Port already in use
Fix: Kill process or change PORT in .env

Issue: Chat doesn't work
Fix: Verify Tuya credentials in .env

Issue: 3D avatar not showing
Fix: Check browser WebGL support, see console

See: README.md Troubleshooting section for more
