GETTING STARTED
═══════════════════════════════════════════════════════════════════════════════

STEP 1: READ DOCUMENTATION
  → Open: START_HERE.md
  → Choose your path (Quick start or detailed)

STEP 2: INSTALL DEPENDENCIES
  $ npm run setup

STEP 3: CONFIGURE BACKEND
  → Edit: backend/.env
  → Add Tuya AI credentials (get from https://iot.tuya.com)

STEP 4: START DEVELOPMENT
  $ npm run dev

STEP 5: USE THE APP
  → Open: http://localhost:5173
  → Register account
  → Start chatting!

TIME TO SETUP: ~30 minutes
