## ⚠️ Troubleshooting

**Blank page?**
- Wait 15 seconds
- Refresh page (F5)
- Check console (F12) for errors

**API error?**
- Backend might not have started
- Check terminal for backend logs
- Verify MongoDB connection in backend/.env

**3D avatar not showing?**
- Refresh page
- Check WebGL support in browser
- Not all browsers fully support it (but functionality still works)

**Login fails?**
- Check MongoDB connection
- Look at backend logs
- Verify .env files have credentials
