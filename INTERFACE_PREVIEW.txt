═══════════════════════════════════════════════════════════════════════════════
                          USER INTERACTION FLOW
═══════════════════════════════════════════════════════════════════════════════

1. ARRIVAL
   → See login page (dark, modern)
   → Can register or login

2. REGISTRATION
   → Fill email, password, confirm
   → Click "Register"
   → Redirected to login

3. LOGIN
   → Enter credentials
   → Click "Login"
   → JWT token created
   → Redirected to dashboard

4. DASHBOARD
   → See 3D avatar
   → Select persona
   → Choose gender
   → Ready to chat

5. CHAT
   → Type message
   → Click "Send"
   → Message displayed (right side)
   → AI responds (left side)
   → Avatar animates
   → Message saved to database

6. PERSONALIZATION
   → Switch persona anytime
   → Change avatar gender
   → View chat history
   → Continue conversation

7. LOGOUT
   → Click logout (top right)
   → Token cleared
   → Redirected to login
   → Session ended

═══════════════════════════════════════════════════════════════════════════════
                         BACKEND API INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

ALL REQUESTS SHOWN TO USER:

Registration:
  POST /api/auth/register
  {email, password} → Success or error message

Login:
  POST /api/auth/login
  {email, password} → Token stored in localStorage

Send Message:
  POST /api/chat/message
  {content, personaId, sessionId} → AI response

Get History:
  GET /api/chat/history/:sessionId
  → Returns all messages

Get Sessions:
  GET /api/chat/sessions
  → Returns user's past chats
